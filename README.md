# Origami for Kids 📄✨

Fold-along paper crafts for ages 6–12 from [@Kids.JoinDev](https://www.youtube.com/@Kids.JoinDev). Vector fold sheets, quiet video lessons (playlist **Origami for Kids** — coming soon), and a light coding/maths link in every topic (symmetry, angles, sequences as algorithms).

Website: https://dev-repos.github.io/kids-origami-projects/

Every topic lives in its own folder under `projects/` with a kid-facing guide (`README.md`), a **Finished!** result drawing (`final.png`), and **true-size A4 fold sheets** (`templates.pdf` at A4 210×297 mm — the preferred print file — plus `page-N.png` at 300 dpi, 1 mm ≈ 11.811 px, and `page-N.svg`). New topics are added to this same repo.

## How to print (true-size A4)

1. Open `templates.pdf` for the project.
2. In your print dialog choose **100% / Actual size** (or “no scaling”).
3. Do **not** choose “fit to page” / “shrink to fit”.
4. After printing, measure the black **100 mm** calibration bar with a ruler. It must be exactly 100 mm. If not, print again.
5. Cut the square on the solid outer edge if your paper is not already square (default square = **150 × 150 mm** unless the project says otherwise).

## Symbol key

| Mark on the sheet | Meaning |
|-------------------|---------|
| Dashed **blue** line | **Valley** fold — fold the paper toward you |
| Dash-dot **red** line | **Mountain** fold — fold the paper away from you |
| ↻ | Turn the model over |
| → arrow | Direction to fold |
| Number badge | Step order (follow in sequence — it is an algorithm!) |
| ★ Finished! | What the model should look like at the end |
